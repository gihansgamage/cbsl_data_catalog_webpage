CBSL Data Catalogue – User Guide

Use this guide to find datasets, narrow the catalogue to the information you need, and download the results.

1. Filters – Find the datasets you need

Open Data Catalogue to view the dataset list and its filters. Filters help narrow the list without changing the source catalogue.

  • Department: Select one or more departments to show datasets belonging to those departments.
  • Topic: Select one or more topics to narrow the list by subject.
  • More filters: Expand this option to access additional available filter fields. Select one or more values in any field.
  • Keywords: Enter a word or phrase to search across dataset fields. Matching text is highlighted in the results.
  • Search within a filter: Open a filter dropdown and use its search box to find an option quickly.
  • Clear: Use the Clear link inside a filter to remove that filter, or select Clear filters to reset all selected filters and the keyword search.

How combined filters work: Selecting several values within the same filter shows records matching any of those values. When you use different filters together, a dataset must match the selections in every selected filter. The keyword search is applied as an additional search condition.

2. Download

Select Download to export the datasets currently shown in the results table as an Excel workbook. The export follows your active filters and includes only the columns selected in the Columns panel.

3. Last Updated

In the Data Catalogue view, the header shows the date and time when the source Excel workbook was last modified. The dashboard checks the connected workbook for changes and updates the displayed data automatically.

4. Columns – Choose what to display or download

Open Columns to open the Fields to download panel, where you choose which fields you want to see in the results table and include in the Excel download.

  • All: Select every available column.
  • Mandatory: Select the columns marked as mandatory for the catalogue.
  • None: Clear the column selection. You can then select only the individual columns you need.
  • You can also tick or untick individual columns to customize the displayed and downloaded information.
  • Field Definitions: Select the Field Definitions eye icon, next to All / Mandatory / None, to show a short definition under each field name. This helps you understand what a field contains before you select it. Select it again (closed-eye icon) to show field names only.

5. Statistics Panel

The Statistics panel summarises the catalogue data. The home page shows overall department and dataset totals, with charts for Information Classification and Access and Sharing Level. In the Data Catalogue view, overall statistics remain visible and a second section, “Current Selection”, updates to reflect the active filters.

Use the panel toggle to show or hide the Statistics panel when you need more room for the dataset table.

Tip: Apply your filters first, choose the columns you need, review the matching dataset count, and then select Download to export that view.
CBSL Data Workflow

Build the Data Catalogue

1. The CBSL should establish a data catalogue based on the existing data inventory. The catalogue should be developed in two stages. The first stage should create a practical dataset-level catalogue showing what data the CBSL holds, who owns each dataset, who can access it, and what it is used for. This should be delivered quickly because it directly addresses departmental need to find existing data and reduce duplicate requests. The second stage should expand the catalogue² during platform implementation.

Footnotes:

  • A fuller catalogue includes field-level detail (knowing what each field is, not just each dataset), data lineage (where each data point came from, so when there is a quality issue, it can be traced back), and validation rules (rules that travel with the data).
  • Generic Statistical Business Process Model: international framework for standardizing statistical production processes.

2. The first draft of the catalogue should be built in three steps. First, the CBSL should normalize the existing inventory, agree what one catalogue record represents, remove duplicates, and clean existing metadata. Second, it should complete partially filled fields, including contact point, description, division, classification, and internal shareability. Third, it should publish the catalogue together with a simple request and overlap-check workflow. This work should be led by the DGU with support from departmental data stewards.

3. The catalogue should be paired with a simple request and overlap-check workflow. Departments should first check the catalogue to see whether the data is already collected elsewhere. If no overlap is found, the Director may approve the new collection under departmental authority. If overlap is detected, the DMC should assess value versus reporting burden, with escalation to the DMOC where needed. New datasets should then be registered in the catalogue with a description, classification, owner, and access level. This workflow reduces duplicate requests on external intuitions in the short-term and gives departments visibility of what is already available across the CBSL (see Data Catalogue and Request Flow Diagram of Appendix 1).

Connect this page to the catalogue folder

Select the folder containing CBSL_Data_Catalog.xlsx. Because the public page and admin page are separate local HTML files, select the same folder once on each page. The dashboard will then check the workbook for updates automatically.

Use Chrome or Edge. Browser security requires this folder permission; a local HTML page cannot silently scan neighbouring files.

Download Excel template

Select a department only. The Excel workbook will download immediately with that department's catalogue worksheet and the reference worksheets.

Important: This is a temporary data-entry session.The information you enter here is not saved to the local Excel workbook or the catalogue folder. When you finish, download the completed Excel file and keep it. To continue editing later, import that downloaded Excel file again.
